# Telegram Gemini AI Bot

A Telegram chatbot powered by Google's Gemini AI. The bot allows users to ask questions and receive AI-generated responses directly in Telegram.

## Overview

The project demonstrates the integration of a Telegram bot with Google's Gemini API, creating a simple conversational AI assistant.

Users can send text messages to the bot and receive responses generated by the Gemini model.

## Features

- **Gemini AI Integration** — Generates responses using Google's Gemini API.
- **Telegram Bot Interface** — Interacts with users directly through Telegram.
- **Real-time Responses** — Processes incoming messages and returns AI-generated answers.
- **Typing Indicator** — Displays a typing status while generating a response.
- **Basic Rate Limiting** — Prevents users from sending messages too frequently.
- **Error Handling** — Handles API and message-processing errors.

## Setup and Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Telegram-Gemini-AI-Bot.git
cd Telegram-Gemini-AI-Bot
```

### 2. Install dependencies

```bash
pip install python-telegram-bot google-generativeai
```

### 3. Configure API keys

You need two API keys:

- **Telegram Bot Token** — Obtain it from [@BotFather](https://t.me/BotFather).
- **Gemini API Key** — Get it from [Google AI Studio](https://aistudio.google.com/apikey).

Set your credentials in the project:

```python
TELEGRAM_TOKEN = "YOUR_TELEGRAM_TOKEN"
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
```

**Security note:** Never upload real API keys or tokens to GitHub. Use environment variables to store sensitive credentials.

### 4. Run the bot

```bash
python bot.py
```

Once started, the bot will be available on Telegram.

## How It Works

1. A user starts the bot using the `/start` command.
2. The bot receives a text message.
3. The message is sent to the Gemini AI model.
4. Gemini generates a response.
5. The bot sends the generated response back to the user.
